# Phase 1 Subring Prefix with full-size ciphertext storage

Accepted on 2026-10-12. Phase 1 retains the implemented Subring Prefix with
full-size ciphertexts and NTTs: the sparse secret has coefficient support on
multiples of 16, and Stage 1 automorphisms preserve it without key switching.
Stage 2's single-digit AKS and bounded CRT projection require centered small
components, supplied by the bootstrap ModUp path and retained by this prefix.

This supersedes the ordinary full-ring BSGS Stage 1 decision in ADR-0003.
Acceptance experiments showed ordinary BSGS passes its isolated main-secret
Stage 1 test, but its output fails the following LCR stage for both word types.
The bounded CRT/single-digit implementation cannot be treated as a general
operator on uniform full-Q ciphertext components. The owner chose to retain
the supported input contract and revise Phase 1 scope, rather than expand the
project into a redesign of that interface during acceptance.

Phase 1 accepts full packing, first width 4, a subring-supported sparse input
secret, and the centered coefficient bounds documented on LCROperator. Stage
2 switches to the main secret. No ring dimension drop or reduced-size GPU NTT
is introduced; those optimizations remain Phase 2. This scope supports neither
arbitrary main-secret CtS inputs nor an IND-CPA claim for the contract test
ciphertexts generated by the testing-only UserInterface.
